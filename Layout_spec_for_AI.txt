Define a class based on toga for the gui (inheriting from toga.App).

Start with a horizontal box at the top for show selection:
- Labelled "Show:"
- A combo box (toga.Selection) to select the show
- A "Fetch" button directly to the right to refresh the show catalog from the TWiT API or fallback feeds
- A "Next" button directly to the right of "Fetch" to grab and append the next page of episodes for the selected show

Directly below the Show section have a horizontal box for episode search:
- Labelled "Search:"
- A text input (toga.TextInput) for entering episode search keywords or topics scoped to the selected show
- A "Search" button to execute search queries against the TWiT API search endpoint and fallback RSS feeds
- A "Clear" button to clear the search input and restore the full episode catalog for the selected show

Directly below the Search section have a horizontal box of episode sorting types:
- Labelled "Sort by:"
- Simulated radio buttons for sort types: Date (default: selected "☑ Date"), Episode Number ("☐ Episode Number"), and Episode Title ("☐ Episode Title")
- Direction toggle button: "▼ Descending" / "▲ Ascending" (toggles server-side API sort order and table ordering)
- Simulated checkbox for format selection: "☐ Audio Only" / "☑ Audio Only" (persists selection across executions via TWITAUDIOONLY)

Below this is a label "Episodes:" followed by a multi-column table (toga.Table) of the selected show's episodes sorted by the selected sort type:
- Table columns/headings: "Episode", "Title", "Date", "Length"
- Displays episode length formatted in hour:minutes:seconds (HH:MM:SS)
- Supports multiple selection for batch downloading
- Activating/double-clicking an episode row triggers streaming
- Enables automatic horizontal and vertical scrollbars when episode titles or column contents exceed visible horizontal space
- Hovering the mouse pointer over any episode entry in the table for more than 3 seconds displays a modal dialog with all metadata about that episode (show, episode number, title, airing date, duration, ID, link, media URL, available formats, hosts/guests, and full description/show notes), with clickable buttons for Web Link and Media URL that invoke the system default browser

Below the episodes table are a horizontal group of action buttons:
- "Download" (initiates multi-threaded background download of selected episodes; on completion, pops up a modal dialog displaying the destination folder at top and downloaded filenames, one per line, with a close button)
- "Stream" (launches external player stream for the selected episode)
- "Cancel" (cancels running downloads)
- "Close" (exits the application window)

Below the buttons is a vertical container with controls for the following settings:

API Application ID (TWITAPI_APPLICATIONID)
    Horizontal row with label "API Application ID:" and a text input for the TWiT 3Scale Application ID.

API Application Key (TWITAPI_APPLICATIONKEYS)
    Horizontal row with label "API Application Key:", a text input for the TWiT 3Scale secret Application Key,
    and a "Test API" button that validates the API credentials against the TWiT REST API and displays a modal dialog with pass/fail status and a close button.

twitcluburl (TWITCLUBURL)
    Horizontal row with label "TWIT Club URL:", a static label prefix showing
    "https://twit.memberfulcontent.com/rss/9041?auth=", a text input for the unique authentication key
    portion of your Club TWiT membership feed, and a "Show" button that fetches and formats the Club TWiT feed with CSS styling (feed-style.css) and displays it in the default web browser.

twitclubdestination (TWITCLUBDESTINATION)
    Horizontal row with label "Download Destination:", a text input for the target download folder,
    and a "Browse" button opening a native folder selection dialog.

twitclubblocksize (TWITCLUBBLOCKSIZE)
    Horizontal row with label "Block Size:" and a text input for the download stream chunk read size
    (default: 8192).

twitclubstreamer (TWITCLUBSTREAMER)
    Horizontal row with label "Streamer:" and a text input for the command line media player.
    The stream URL is represented by %f (default: "vlc %f").

At the bottom of the form is a progress bar (toga.ProgressBar):
- Displays real-time download progress for the batch when downloading episodes.

Application Menu Commands (under toga.Group.HELP):
- "View README Documentation": Opens an integrated hybrid documentation viewer window (toga.WebView) with HTML sanitization, Table of Contents anchor navigation, floating return button, and fallback to default system browser.
- "View API Specification (twittv.apib)": Opens the TWiT REST API Blueprint specification in the sanitized hybrid document viewer.
- "Get TWiT API Key": Opens the official TWiT 3Scale Developer Portal (https://twit-tv.3scale.net) in the default web browser.
